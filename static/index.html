认证

Token 和 Session 至少填一个；留空即未设置。

登录方式

用 OAuth 自动登录时勾选；账号密码统一在「账号池」里维护。

站内账号密码 可选

部分站点需要用户名密码登录，签到时会自动使用。

删除账号

只从本地 accounts.json 删除，不会影响已导出的 GitHub Secret。

账号池

账号详情里勾选「使用 Linux.do / GitHub 登录」后，签到时会从这里取账号。可增、可改、可删。

自定义站点

不在内置列表里的站点，需要在这里配置接口路径。留空的字段使用 NewAPI 默认值。

运行选项

写入 .env，GitHub Actions 需要导出后才生效。

导出到 GitHub

复制 APP_CONFIG，粘贴到仓库 Settings → Environments → production → Secrets。

本地文件

数据保存在本地，不会上传。
